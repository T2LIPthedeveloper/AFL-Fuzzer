Verdict

How they work

Greptile: indexes repo into a function/class/import graph (AST-level entities + relationships); v3 agentic loop uses codebase search / learned rules for multi-hop reasoning; posts summary, P0–P2 inline, confidence 0–5, diagrams; optional TREX sandbox execution.

GitHub Copilot (product): PR/IDE reviewer; Lite vs Balanced effort; agentic “full project context” via Actions; MCP/skills optional; Comment-only (no approve); AI credits.

Copilot here (Cursor): Bugbot on main...develop-N diffs; severity findings; no GitHub bot packaging.
